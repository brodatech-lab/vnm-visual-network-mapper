
VNM - Visual Network Mapper (Linux / Windows Desktop App) - Założenia Architektoniczne i Funkcjonalne

1. Cel i Wizja Projektu
Natywne narzędzie desktopowe dla Linuxa przeznaczone dla inżynierów sieciowych, pentesterów i administratorów homelabów. Aplikacja skupia się na przejrzystym, płaskim interfejsie 2D (schematycznym układzie blokowym/drzewiastym), zapewniając błyskawiczny start, zerowe opóźnienia i czytelną nawigację po topologii sieci oraz wynikach skanowania.

---

2. Architektura Natywnej Aplikacji Desktopowej 2D
WARSTWA PREZENTACJI (DESKTOP UI 2D)

• Tech Stack: C++20 / Rust + Dear ImGui / Qt6 / GTK4 + Cairo/Skia/2D Canvas.

• Okno & Wyświetlanie: Natywne okno X11 / Wayland (wsparcie HiDPI, obsługa gestów/myszy). Windows aplikacja exe.

• Interfejs: Płaski graf 2D (węzły, krawędzie, podsieci /24, zoom & pan, minimapa), Docking Windows (Inspector, Tabela Portów, Terminal Output).

CORE ENGINE & NETWORK ORCHESTRATOR

• Tech Stack: C++ / Rust (Multithreaded Task Engine).

• Komponenty:

  • Wykonawca skanów (Nmap CLI Wrapper / Direct Libpcap / Raw Sockets).

  • Async Parser XML/JSON & Normalizator Pamięciowy.

  • Silnik Topologii 2D (Algorytmy klastrowania 2D / Sugiyama Layout).

LOCAL STORAGE & ENGINE

• Engine: Nmap / Masscan / Libpcap.

• Database: SQLite (Local DB) / JSON.

---

3. Kluczowe Założenia Technologiczne (Linux Native Stack)
• Język Główny: C++20 lub Rust – czysty kod natywny, brak ciężkich środowisk wykonawczych (Electron/WebViews), start w ułamku sekundy, zużycie RAM < 50 MB.

• GUI & Renderowanie 2D: Dear ImGui (Docking Mode) / Qt6 / GTK4 z wektorowym canvasem 2D (ImDrawList, Cairo lub Skia) i obsługą Zoom & Pan.

• Uprawnienia Sieciowe: Wykorzystanie `raw sockets` i `libpcap` z uprawnieniami `setcap cap_net_raw,cap_net_admin=eip ./visnmap`.

---

4. Główne Moduły i Funkcjonalności
A. Natywny Silnik Skanowania i Parser Pamięciowy

• Asynchroniczny Process Runner: Uruchamianie `nmap` / `masscan` w osobnym wątku za pomocą POSIX `execve`/`pipe` i przechwytywanie strumienia XML/JSON na żywo.

• Szybki Parser Pamięciowy: Ładowanie urządzeń bezpośrednio do ciągłych struktur w pamięci (vektory C++/Rust).

• Auto-Detection Interfejsów: Odczyt interfejsów i tabeli routingu z `/sys/class/net/` i `/proc/net/route`.

B. Przejrzysta Mapa Topologii 2D (2D Canvas Topology)

• Strukturalny Układ Blokowy: Czytelne kafelki 2D, klastrowanie w ramki podsieci (`192.168.1.0/24`), linie połączeń `traceroute`.

• Statusy i Kolorystyka:

  • 🟢 Zielony: Host aktywny, bezpieczny.

  • 🟡 Żółty: Wykryte otwarte porty wymagające uwagi.

  • 🔴 Czerwony: Krytyczne podatności (NSE/CVE) / nieznany host.

  • ⚪ Szary: Host offline.

• Nawigacja: Minimapa, wyszukiwanie i filtrowanie (np. `port:22`).

C. Zintegrowany Inspector & Docking Panel

• Node Details: IP, MAC, Vendor (OUI), OS Detection Confidence.

• Tabela Usług & Raport Podatności: Otwarte porty, wersje usług, skrypty NSE z oceną ryzyka.

• Szybkie Akcje Systemowe: Wywoływanie sesji SSH w terminalu systemowym, odnośniki do `ping`, `traceroute`, `Wireshark`.

---

5. Zaawansowane Funkcje Dodatkowe
1. Pasywne Wykrywanie (pcap Thread): Dyskretny wątek nasłuchujący pakietów ARP/DHCP w tle.

2. Diffing i Historia (Time Travel): Zapis w SQLite (`~/.config/visnmap/storage.db`) i porównywanie skanów.

3. Eksport: Zrzut schematu do SVG, PNG, JSON lub PDF.

Dlaczego projekt NetVector (C++20/Rust + ImGui/Cairo 2D) ma sens?
Ekstremalna Wydajność (C++ / Rust): Dzięki zrezygnowaniu z Electrona i web-stacka, aplikacja włącza się w 50 ms, zużywa 30-50 MB RAM i potrafi wyrenderować tysiące węzłów z płynnością 60+ FPS na silniku canvasu 2D.

Klastrowanie podsieci 2D (Network Grouping): Żadne darmowe narzędzie open-source nie robi ładnego, automatycznego układania kafelków w ramki podsieci /24 na bazie danych z Nmapa z podświetlaniem statusów bezpieczeństwa (Zielony/Żółty/Czerwony).

Idealne narzędzie dla Homelabów i Pentesterów: Możliwość uruchomienia jednej natywnej binarki na Linuxie (./netvector), udostępnienie jej uprawnień setcap i natychmiastowy interaktywny podgląd całej sieci lokalnej bez instalowania Node.js, Pythona, Dockerów czy stawiania serwerów www.
